<CodeBlock language="markdown" editable> # QUIZ//SHIFT ### The Quiz That Changes Rules

QUIZ//SHIFT is a terminal-based quiz game developed in C. It combines knowledge challenges, scoring, streaks, and player profiles in an interactive quiz experience.

Features

Multiple-choice quiz questions

Science and other knowledge categories

Difficulty-based challenges

Score and streak tracking

Explanations after answering

Player profile and high-score menu

Technologies Used

C Programming

GCC Compiler

Standard C Libraries

How to Run

Compile the project using GCC:

gcc main.c game.c questions.c scoring.c -o quizshift.exe

Run on Windows:

quizshift.exe
Project Structure

main.c – Main menu and program entry point

game.c – Gameplay logic

questions.c – Question bank

scoring.c – Scoring system

Header files – Function declarations
